# Journal reading pages

Help adapts the reading-page layout and relevant text from the
CX16 Kakuro application's `src/HELP.TXT`, `src/docview.c`,
and `assets/scripts/create_documents.py`. The DOS version uses the existing
journal background, framed paper panels, ProFont headings, BIOS reading text,
and a scroll bar. No new background images are required.

Text is adapted to implemented DOS features: keyboard selection and entry,
rule-based completion, 96 boards, session-only status, and compressed resources.
CX16-specific mouse, music, timer, and checking controls are omitted.

Edit `HELP.TXT` here and run
`python3 tools/generate_documents.py` to produce `src/DOCDATA.H`. The generator
joins wrapped source lines into paragraphs and wraps them to 60 columns.
Source paragraphs may be formatted to 80 columns. Keep each `# ` heading on
its own line, with a blank line after it; use blank lines between paragraphs.
Each `- ` line starts a separate bullet, with indented continuation lines. The Help viewer shows 18 rows, scrolls without image
I/O, and supports arrows, Page Up/Down, Space, Home/End, and Escape/Enter to
return to the same journal selection. The release compiles the text into the
executable; these source files need not be shipped.

About is a small modal over the dimmed journal. It shows only the version,
author, compiler, UTC build time, Git commit ID, and repository link. These fields come from
`src/BUILDINF.H`, regenerated by `tools/generate_buildinfo.py` during every
DOS build. `VERSION` is the release version source. The build captures the
host Git checkout's short HEAD ID, including when compilation uses Docker.
For source exports without Git metadata, the commit field reads "unavailable";
set `BUILD_COMMIT` to a known commit ID to supply it. `SOURCE_DATE_EPOCH`
can set a reproducible build timestamp. About ignores scrolling keys and
closes with Escape or Enter.
